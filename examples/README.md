# PitchBook Scraper API – code examples

Examples for every PitchBook endpoint of the [Piloterr API](https://www.piloterr.com). Python and TypeScript examples are in the [main README](../README.md).

```bash
export PILOTERR_API_KEY="your-api-key"   # get one at https://app.piloterr.com
```

| Language | File | Run |
|---|---|---|
| cURL (Bash) | [`curl/company_info.sh`](curl/company_info.sh) | `bash company_info.sh` |
| cURL (Bash) | [`curl/search.sh`](curl/search.sh) | `bash search.sh` |
| PHP | [`php/company_info.php`](php/company_info.php) | `php company_info.php` |
| PHP | [`php/search.php`](php/search.php) | `php search.php` |
| C# | [`csharp/CompanyInfo.cs`](csharp/CompanyInfo.cs) | `copy to `Program.cs`, `dotnet run` |
| C# | [`csharp/Search.cs`](csharp/Search.cs) | `copy to `Program.cs`, `dotnet run` |
| Go | [`go/company_info.go`](go/company_info.go) | `go run company_info.go` |
| Go | [`go/search.go`](go/search.go) | `go run search.go` |
| Java | [`java/CompanyInfoExample.java`](java/CompanyInfoExample.java) | `java CompanyInfoExample.java` |
| Java | [`java/SearchExample.java`](java/SearchExample.java) | `java SearchExample.java` |
| Ruby | [`ruby/company_info.rb`](ruby/company_info.rb) | `ruby company_info.rb` |
| Ruby | [`ruby/search.rb`](ruby/search.rb) | `ruby search.rb` |
| Node.js | [`nodejs/company_info.mjs`](nodejs/company_info.mjs) | `node company_info.mjs` |
| Node.js | [`nodejs/search.mjs`](nodejs/search.mjs) | `node search.mjs` |
